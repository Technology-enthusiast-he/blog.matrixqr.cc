## 🌟 Features
* **Multiple Formats:** Supports WiFi Network configurations, Communications Phone numbers, and vCard Electronic Business Cards.
* **Multi-Language UI:** Fully localized in English, Deutsch, Italiano, Türkçe, 한국어, and 简体中文 (Default: English).
* **Zero Server Overhead:** Pure client-side JavaScript rendering with exceptional cross-browser canvas compatibility.
* **Premium Tech UI:** Matrix-inspired dark tech aesthetic with fully responsive grid layouts.

## 📂 Deployment on Vercel
This project is fully optimized for Vercel edge networks. Since it contains only static files, it deploys instantly with zero configuration.

### 简体中文说明

MatrixQR 是一款基于纯前端的高级科技感二维码生成终端，专为 Vercel 边缘网络优化，开箱即用。

#### 功能亮点
* **多场景支持**：支持 WiFi 自动连接、手机号呼叫、国际化 vCard 电子名片生成。
* **六国语言联动**：内置英、德、意、土、韩、中六国语言包，UI 与输入提示实时同步切换。
* **零配置部署**：纯静态单文件结构，导入 Vercel 即可秒级完成全球 CDN 部署。
